# Origins
FastLeanIO is a breaking fork of ecyrbe/leanio, via adamritter/leanio commit 712d351d45d8947ad494d0836bacca0de34d8c00, and the native/Action backend of adamritter/leanio-fasthttp commit 6b6639c95564d1841c950709156bd8d4bcb3f573. Original MIT notices are retained. FastHTTP is the only package dependency. The former Std.Http server entry point is removed.
